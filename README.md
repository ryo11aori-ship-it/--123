# 極・五厘賽チンチロ 3D — 物理シミュレータ版

5個のサイコロと独自ルールで競む 3D チンチロリン。
**サイコロの動きは、このプロジェクト専用に書いた剛体物理シミュレータで計算しています**（外部の物理エンジンは使っていません）。

## 起動

```bash
npm install
npm run dev        # http://localhost:3000
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド |
| `npm run lint` | 型検査 (`tsc --noEmit`) |
| `npm run verify:physics` | 物理シミュレータのモンテカルロ検証 (公平性・貫通・再現性・凹凸の影響・速度)。`-- --quick` で簡易版 |
| `npm run verify:mesh` | 描画メッシュの検証 (面の向き / **見えているお椀の面と当たり判定の一致**) |

操作: **Space / Enter** で投擲、画面ドラッグで視点回転、ホイール/ピンチでズーム。
右端の歯車 → 物理ログと設定 (お椀の凹凸の強さ・再生速度・明るさ)。

## ルールについて

ゲームのルール (`src/game/evaluator.ts`・`src/types/game.ts`・`App.tsx` の勝敗/サドンデス/順位の処理) は
**元のまま一切変更していません**。ションベンの発生確率「1投擲あたり固定1%」も仕様どおりです
(`SHONBEN_RATE`, `src/game/threeScene.ts`)。ションベン時は、実際に物理で椀外へ飛び出す投擲を探して再生します。

## 構成

```
src/
  physics/            自作の物理シミュレータ (依存なしの純TypeScript。Node でも動く)
    bowlProfile.ts      お椀の断面(母線) — 見た目と当たり判定の唯一の形状ソース
    bowlBump.ts         お椀内面の凹凸マップ (ろくろ目・槌目・ピンホール・釉だまり)
    bowlModel.ts        断面SDFの焼き込み + 凹凸を重ねた衝突クエリ
    world.ts            剛体ワールド (接触検出・ソルバ・積分・スリープ)
    throw.ts            投擲の初期条件 (人が椀の上から放り込む動作)
    rollJob.ts          1投擲を最後までシミュレーション → 判定(椀外/傾き/重なり) → 記録
    recording.ts        記録と再生用サンプリング
    rng.ts              暗号論的乱数 + 操作ゆらぎのエントロピープール
  render/             描画用メッシュ(three非依存) とテクスチャ
  game/threeScene.ts  three.js シーン。物理の記録を再生する
  audio/              効果音 (衝突イベントごとにモーダル合成)
scripts/              検証スクリプト
docs/                 調査レポート
```

詳しい原因調査・設計・検証結果は [`docs/原因調査と物理シミュレータ設計.md`](docs/原因調査と物理シミュレータ設計.md) を参照してください。
